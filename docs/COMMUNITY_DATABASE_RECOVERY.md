# إصلاح خطأ تسجيل الدخول P2022 بعد تحديث المجتمع

السجلات تؤكد غياب `users.communityMentionNotifications` و`CommunityPost.mediaIds` و`CommunityStory.mediaIds`. إعداد Render الحالي يشغّل `node dist/main.js` مباشرة، فلا يطبق ترحيلات Prisma. وسجل الإنتاج سبق أن واجه P3005؛ لهذا لا يكفي تغيير أمر التشغيل إلى migrate deploy دون إصلاح سجل الترحيلات.

## التنفيذ

1. في Neon، اختر مشروع قاعدة التطبيق وفرع الإنتاج الصحيح، وأنشئ فرع نسخة احتياطية أو نقطة استعادة قبل التعديل.
2. افتح SQL Editor لنفس قاعدة التطبيق.
3. انسخ وشغّل **كامل** ملف [add-mobile-community.sql](../backend/prisma/recovery/add-mobile-community.sql).
4. تأكد من نجاح المعاملة وظهور الأعمدة الجديدة الـ19 في نتيجة الاستعلام الأخير. إذا ظهر خطأ، توقف وأرسل نص الخطأ دون رابط الاتصال أو كلمات المرور.
5. جرّب تسجيل الدخول ثم المنشورات والقصص. الخادم الحالي يستطيع استخدام الأعمدة فور اكتمال المعاملة؛ لا يحتاج هذا الإصلاح وحده إلى نشر كود جديد.

الإصلاح يضيف الأعمدة والجدول والفهرسة وقيد الجمهور. لا يمسح سجلات أو يغير أجسام المنشورات أو جمهور المنشورات الموجودة، ولا يسجل ترحيلات قديمة كمطبقة. يقبل إعادة التنفيذ، ويرفض الأعمدة الموجودة ذات الأنواع غير المتوافقة داخل المعاملة.

لا يعالج الملف سجل ترحيلات الإنتاج أو بقية فروق المخطط القديمة. إصلاح baseline يحتاج مقارنة منفصلة للمخطط الفعلي على نسخة مستعادة. الاختبار الآلي المرفق يستخدم قاعدة PostgreSQL معزولة وبيانات اصطناعية، ولا يتصل بالإنتاج.
