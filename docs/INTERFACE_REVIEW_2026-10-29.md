# توحيد واجهة التطبيق — 2026-10-29

طبقة تنسيق مشتركة في `frontend/src/styles/interface.css` توحّد الخط المحلي Tajawal، البطاقات، الحقول، الأزرار، رؤوس الصفحات والجداول. تستخدم ألوان الوضع الحالي، وتقلل الحركة عند تفعيل تفضيل النظام. لم تُعدّل الصلاحيات أو البيانات أو مسارات المزامنة.

أيقونات شريط الجوال أصبحت SVG محلية موحّدة بدلاً من الرموز التعبيرية. يحافظ مكوّن الأيقونات على صنفه الأساسي عند تمرير صنف إضافي.

## التحقق الفعلي

- بناء الإنتاج Vite: ناجح، مع تحذيرات الحزم الكبيرة والاستيرادات الديناميكية الموجودة.
- TypeScript بدون إصدار ملفات: ناجح.
- Playwright `playwright.personal.config.ts`: سبعة اختبارات ناجحة.
- فحص عدم وجود تجاوز أفقي عند عرض 360 و390 و1280 بكسل، ووجود خمس أيقونات SVG في شريط الجوال وأهداف لمس لا تقل عن 44 بكسل.
- فحص الوضع الليلي وإعداد تقليل الحركة، مع صور للواجهة في مخرجات الاختبارات.
- اجتازت طلبات الإذن للطالب والمحفظ، الحفظ دون اتصال وإعادة الإرسال، المحادثة مع محاكاة لوحة المفاتيح، صفحة الدخول، صورة المسجد دون اتصال ومعاينة الأذان اختبارات الانحدار.
- فُحصت صورة صفحة الإذن عند عرض 390 بكسل بصرياً.

## حدود التغطية

التغييرات تشمل المكوّنات المشتركة، وليست شهادة بمراجعة كل صفحة وكل نوع مستخدم بصرياً. الصفحات ذات التنسيق المستقل تحتاج مراجعة إضافية. لم تُنتج APK جديدة ولم تُجرّب سلاسة WebView أو لوحة المفاتيح على هاتف فعلي. اختبارات المتصفح تستخدم بيانات اختبار معزولة، ولم يُمسّ الإنتاج.
