# خطة تجربة الجوال وهوية المدرسة — 2026-11-04

## المتطلبات المعتمدة
- الحفاظ على الهوية البصرية للمدرسة، وليس استنساخ واتساب.
- أيقونة المحادثات تبقى أعلى الواجهة في مكانها؛ عند الضغط تفتح شاشة محادثات كاملة ببحث علوي، زر محادثة جديدة أسفل الجانب وزر مجموعة فوقه. المحادثة نفسها تملأ الشاشة ويظل شريط الكتابة مرئياً.
- تصميم Mobile First لكل الصفحات، مع مراعاة safe areas ولوحة المفاتيح وتجنب التمرير غير الضروري؛ المحتوى الطويل يبقى قابلاً للتمرير.
- الملف الشخصي وفق الرسوم المرفقة: غلاف، صورة شخصية، نبذة، منشورات، تفاعلات، وإجراءات واضحة.
- محرر ستوري بصفحة مستقلة مع لون الخلفية ولون النص وتنسيقه ومنشن داخل النص.
- محرر منشور بصفحة مستقلة مع جمهور «الكل» أو أشخاص محددين، منشن داخل النص، وخيار نشر الإدارة باسم الحساب أو المدرسة.
- الإعدادات الأصلية باقية، مع حذف «تنبيهات الطوارئ» و«منشن للذات» فقط.
- الإشعارات: صوت الإشعارات، تحديد الإشعارات، صوت الأذان، تذكير الأذان.
- التخصيص: مظهر نهاري وليلي.
- الحساب: الملف الشخصي، تغيير كلمة المرور، رمز الأمان.
- الجوال: المساعدة والدعم، الأذونات، حول التطبيق وإصداره، سياسة الخصوصية، حذف الحساب، تسجيل الخروج.

## قواعد التنفيذ
- لا نغير صلاحيات الوصول في الخادم دون اختبارات عزل المستخدمين.
- المنشن ليس مجرد نص: يجب حفظ معرف المستهدف والتحقق من صلاحية رؤيته عند النشر والإشعار.
- الجمهور المحدد يطبق على الاستعلامات وواجهات API والوسائط والإشعارات، لا على الواجهة فقط.
- النشر باسم المدرسة يجب أن يقتصر على الإدارة مع حفظ الناشر الفعلي للتدقيق.
- مراعاة وضع الأوفلاين والطوابير وعدم فقد التعديلات.
- فحص أمان الاعتماديات، اختبارات TypeScript والبناء وE2E للجوال قبل الدمج.

## حالة التنفيذ
- أضيفت روابط مجمعة للإعدادات الموجودة إلى صفحة إعدادات الحساب.
- ما تبقى في هذه الخطة غير منفذ بعد ويحتاج تنفيذ واختبارات مستقلة.
