# التسميع على المصحف والحضور ولوحة الشرف

## الاستخدام

من تسجيل التسميع تبقى عدادات الأخطاء والتنبيهات والأحكام كما هي. زر «الأخطاء على المصحف» يفتح صفحة مرسومة بخط QPC V2؛ اضغط كلمة من نطاق التسميع ثم نوع الخطأ لتسجيله مباشرة. الإنهاء يعيد نفس النموذج. العدادات تمثل المجموع بما فيه الكلمات المحددة، والخصم لا يتكرر. تتوفر الملاحظات والحذف والتراجع، والتنقل بالسورة والآية والصفحة. يمكن تفصيل العدادات حسب الأنواع المفعلة.

من زر ضبط القواعد يستطيع المدير تفعيل وإضافة وتعطيل أنواع الأخطاء والتنبيهات والأحكام، وتحديد خصم كل نوع وطريقة إدخاله وأول مرة دون خصم، وضبط أساس الدرجة وحدود التقييم. قواعد الحلقة تتقدم على قواعد المدرسة. يحفظ كل تسميع نسخة قواعده وتفاصيل الخصومات؛ تعديل الملاحظة وحدها لا يعيد التقييم. تظهر أخطاء المصحف للقراءة من سجل الطالب وسجل التسميع وبوابة الطالب، ضمن صلاحيات الطالب الحالية. حسابات أولياء الأمور المتقاعدة لا يعاد تفعيلها.

الحضور يدعم «متأخر» ويحسبه حضورًا في النسبة، وحالات إضافية عبر الإعدادات. نقاط كل حالة ووزن الحضور قابلة للضبط. التصحيح يستبدل مساهمة السجل، وإعادة المزامنة تحتفظ بمعرف العملية ولا تمنح نقاطًا إضافية. الحالات الإضافية تستخدم حالة PRESENT الأساسية للتوافق وتحتفظ بمعرف الحالة المخصصة بشكل مستقل.

تستخدم لوحة الشرف والترتيب الحالية نفس مجموع التسميع والحضور والإنجازات، مع فلاتر المدرسة/الحلقة والأسبوع/الشهر/كل الأوقات. يبدأ الأسبوع الأحد بتوقيت الرياض. تعرض تفاصيل مصادر النقاط، وللمدير سجل حركاتها من شاشة القواعد. الأوزان تطبق عند حفظ السجلات الجديدة، والسجلات القديمة تحتفظ بنقاطها.

## دون اتصال

المسودة وأخطاء الكلمات محفوظة في IndexedDB المشفر للحساب. تستخدم المزامنة الحالية ونسخ القواعد المحفوظة، ويُرفض تحديث قديم عندما يحمل إصدارًا لم يعد مطابقًا. زر تنزيل المصحف يحفظ الصفحات والخطوط والفهرس في التخزين العام؛ لا يخزن أخطاء الطلاب في CacheStorage. أصول المصحف مرفقة أيضًا ببناء تطبيق الهاتف. الصورة الشخصية تبقى للرفع مع الإنترنت فقط، ورفع الغلاف يبقى معطلًا.

## المصادر والتحقق

- النص ومعرفات الآيات: https://api.quran.com/api/v4
- التخطيط ومعرفات مواضع الكلمات: https://qul.tarteel.ai/resources/mushaf-layout/10
- خط مجمع الملك فهد QPC V2: https://qul.tarteel.ai/resources/font/249/docs
- توثيق الخط البديل المطابق: https://api-docs.quran.com/docs/tutorials/fonts/font-rendering/

ينبغي إبقاء نسب المصادر وحقوق أصحاب الخطوط. صفحة QUL الخاصة بالخط لا تعرض ترخيص إعادة توزيع محددًا؛ ترخيص تطبيق المدرسة لا يُنسب إلى الخط أو النص. ملفات manifest تحفظ SHA-256 لكل صفحة وخط. فحص scripts/verify-mushaf.mjs يتحقق من 604 صفحات و6236 آية ومعرفات مواضع غير مكررة وتطابق عقد الحساب في المتصفح والخادم. لا تتولد الآيات أو مواضع الكلمات بالذكاء الاصطناعي.

لإعادة تنزيل المصادر: scripts/download-mushaf.mjs ثم scripts/download-mushaf-woff2.mjs ثم scripts/download-mushaf-layout.mjs. يلزم تحديث فهرس verse-pages وملف MUSHAF_WORD_POSITIONS بعد تغيير نسخة المصادر، وفحصها قبل اعتمادها.

## قاعدة البيانات والنشر

المهاجرة 20261108120000_mushaf_learning إضافية: تحفظ تفاصيل الكلمات والعدادات وقواعدها، تضيف LATE ونقاط الحضور وقواعد المدرسة/الحلقة وسجل النقاط. لا تعيد تقييم النتائج القديمة، وتنسخ عداد tajweed القديم عند غياب tajweedErrors. تُوقف مشغّل حساب قديمًا كان يستبدل تقييم التطبيق بقواعد منفصلة. المشغلات الجديدة تربط المساهمات برصيد الطالب داخل نفس معاملة الحفظ والمزامنة.

انشر الخادم مع prisma migrate deploy قبل الواجهة الجديدة. لا تستخدم reset أو seed أو وضع علامة نجاح لمهاجرات لم تُطبق. إذا كانت بيئة الإنتاج القديمة لا تشغّل مهاجرات Prisma، يلزم فحص سجلها وتنفيذ ترقية متوافقة قبل تشغيل هذه النسخة. يجب نجاح اختبار PostgreSQL المعزول learning.integration.test.ts واختبارات المتصفح وبناء الويب وAndroid وiOS قبل الدمج للنشر.
