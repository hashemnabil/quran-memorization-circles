# تقرير تغطية العمل دون إنترنت لكل صفحة

هذا جرد للمشروع الحالي، يشمل استدعاءات API المباشرة والعناصر التفاعلية الظاهرة في مصدر كل صفحة، ثم المكونات المشتركة التي تحتوي استدعاءات API. لا يثبت الجرد تنفيذ كل زر أو اختبار كل دور. مسار محلي موجود يعني وجود تنفيذ في الكود، وليس نجاحًا نهائيًا أو اكتمال كل الحالات.

عدد الصفحات: **58**. استدعاءات الصفحات المباشرة: **298**. عناصر تفاعلية/نماذج في مصدر الصفحات: **394**. استدعاءات كتابة تحتاج تحويلًا أو مراجعة: **34**.

## حدود التحقق الحالية

- أول دخول، اعتماد الصلاحيات، استلام بيانات جديدة وPush ورفع الملف فعليًا تتطلب اتصالًا. الحفظ المحلي لا يعني اعتماد الخادم.
- حساب ولي الأمر موقوف حاليًا في auth.service.ts وjwt.strategy.ts؛ لم يُفعّل لتجاوز هذا القيد، ولا توجد دعوى اختبار دخول فعلي لهذا الدور.
- فحص PostgreSQL الحقيقي وAndroid SDK/جهاز فعلي وWorkManager لم يُثبت نجاحه في هذه البيئة.
- القوائم والتقارير المحلية قد تكون جزئية؛ لا تعادل نسخة خادم كاملة. المرفقات المستأنفة والوظائف المصنفة غير مغطاة ليست مكتملة.
