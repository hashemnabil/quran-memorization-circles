# مواقيت غزة وأصوات الإشعارات

التنفيذ في المستودع الحالي، بتاريخ 25 أكتوبر 2026. لم تُشغّل أوامر ترحيل قاعدة البيانات أو إعادة تهيئتها أو نشر الإنتاج، ولم تُعدّل أدوار الحسابات.

## الواجهات

- `frontend/src/components/PrayerCard.tsx`: بطاقة الرئيسية والطالب؛ المواقيت الستة والتاريخان والصلاة القادمة. مؤقت الثواني معزول في مكوّن العدّاد؛ يُنظّف عند المغادرة.
- `frontend/src/pages/PrayerTimesPage.tsx`: `/prayer-times`، صفحة داخلية مع جدول اليوم وزر العودة إلى مصدر الزيارة.
- `frontend/src/pages/PrayerReminderSettingsPage.tsx`: `/prayer-times/reminders`، تفعيل عام وتخصيص كل صلاة ووقت التنبيه وصوته وتصحيح التاريخ الهجري.
- `frontend/src/pages/NotificationSoundSettingsPage.tsx` و`components/SoundPicker.tsx`: `/profile/settings/notifications/sound`، الصوت الافتراضي والصامت وثلاثة أصوات أصلية واستيراد ملف ومعاينته وإيقافه وحفظه.
- `frontend/src/components/AppLaunchGate.tsx`: استعمال الشعار الموجود `public/brand-logo.png` في افتتاحية صامتة وخفيفة؛ المحتوى يبدأ التحميل تحت الافتتاحية. احترام تقليل الحركة، وعدم إعادة الافتتاحية أثناء التنقل الداخلي.
- ربط الميزات في `App.tsx` و`DashboardPage.tsx` و`StudentPortalPage.tsx` و`ProfilePage.tsx` و`AppLayout.tsx`.

الأدوار المفعلة حاليًا: ADMIN وSUPERVISOR وTEACHER وEXAM_COMMITTEE وSUPPORT وSTUDENT. صفحة ولي الأمر موجودة لكن تسجيل دخوله وتحديث جلسته محظوران مسبقًا في `backend/src/auth/auth.service.ts`؛ لم يُرفع هذا الحظر. البطاقة مشتركة في لوحة الأدوار، بما فيها PARENT إن أعيد تفعيل البوابة في عمل مستقل ومصرح به.

## الحساب المحلي

`frontend/src/lib/prayer-times.ts` يستخدم Adhan JS 4.4.3 بإحداثيات غزة 31.5017، 34.4668، وطريقة الهيئة المصرية للمساحة (الفجر 19.5° والعشاء 17.5°، العصر وفق الجمهور). التواريخ تُستخرج من Asia/Gaza، والحساب يعيد لحظات UTC ثم تُنسّق أوقات العرض بتوقيت غزة. لا تُطلب صلاحية الموقع ولا توجد قائمة مدن أو طلب API لحساب المواقيت.

التاريخ الهجري من Intl باستخدام `islamic-civil`، مع تصحيح شخصي من -2 إلى +2 يوم. ليس إعلانًا للرؤية الشرعية. حساب الصيف والشتاء يعتمد قاعدة المناطق الزمنية المضمّنة في الجهاز؛ تحديث قواعد فلسطين في النظام قد يتطلب إعادة فتح التطبيق لتجديد الجدولة.

**الحساب فعلي وليس مواقيت تجريبية ثابتة، لكنه لم يُطابق بعد مع تقويم محلي معتمد لمدينة غزة. يجب إتمام المطابقة في تواريخ صيفية وشتوية وقرب انتقال التوقيت قبل الإصدار العام.** توضح الواجهة طريقة الحساب وعدم اعتماد المطابقة المحلية بعد.

مراجع التنفيذ:

- https://github.com/batoulapps/adhan-js/blob/develop/METHODS.md
- https://capacitorjs.com/docs/v6/apis/local-notifications
- https://developer.android.com/develop/ui/views/notifications/channels
- موقع وزارة أوقاف غزة للرجوع إلى التقويم المحلي: https://www.palwakf.ps/ar/ . لم تُعتمد مواقيت الصفحة الرئيسية غير المؤرخة كمرجع اختباري لغزة.

## تخزين الإعدادات والصوت

إعدادات كل حساب منفصلة بالمفتاح `qc.prayers.v1:<account>` و`qc.notification-sound.v1:<account>`. الأصوات المستوردة محفوظة في IndexedDB داخل نطاق الموقع وبمفتاح الحساب ونوع الصوت. لا تُرفع إلى الخادم. الحد 5 ميجابايت و30 ثانية، مع التحقق من النوع وإمكان فك الصوت قبل الحفظ. قنوات الصوت العامة والصلاة مستقلة.

الأصوات `calm.wav` و`electronic.wav` و`clear.wav` أصلية مولّدة عبر `frontend/scripts/generate-notification-sounds.mjs`، مدتها أقل من ثانية، وتُوزّع مع ترخيص CC0 في `public/sounds/LICENSE.txt`. نسخ Android المطابقة في `res/raw/school_*.wav`. يمكن الاستماع إليها من صفحة الأصوات. لا تتضمن أي تسجيل مرجعي أو أذان أو تلاوة.

`vite.config.ts` يضمّن الأصوات في التخزين المسبق؛ `service-worker.template.js` يسترجعها محليًا عند انقطاع الشبكة. تُطلب ملفات الصوت كنطاق كامل، ويُتحقق من ترويسة WAV واكتمال Content-Range قبل تحويل الاستجابة إلى 200 وتخزينها؛ لا تُقبل استجابات 204 الفارغة أو الملفات الجزئية. كشف الاختبار المحلي اعتراض IDM Advanced Integration لطلبات الصوت العادية؛ لم تُغيّر إعدادات هذا البرنامج. سياسة CSP تسمح بوسائط النطاق نفسه وملفات data/blob المحلية للمعاينة.

اختيار ملف جديد مسودة في الذاكرة حتى الضغط على زر الحفظ؛ مغادرة الصفحة دون حفظ لا تستبدل الصوت السابق.

## أندرويد

`SchoolNotificationsPlugin.java` يجهّز قنوات ثابتة محدودة (6 لكل نوع صوت، 12 إجمالًا) ويحترم تعديلات النظام عليها، ويوفّر فتح إعدادات النظام ومعاينة الصوت الافتراضي. الصوت المستورد يُنسخ إلى ملفات التطبيق الخاصة ويُتاح للنظام عبر FileProvider بمسار محدد. URI الصوت المخصص ثابت لكل نوع؛ بعض الأجهزة قد تتطلب مراجعة صوت القناة في إعدادات النظام بعد استبدال الملف بسبب التخزين المؤقت لدى النظام.

`PrayerAlarmReceiver.java` يحتفظ بجدول محسوب محليًا لـ370 يومًا، ويجدول تنبيهًا واحدًا قادمًا فقط. يتجدد الجدول عند فتح التطبيق واستئنافه، وكل ساعة أثناء تشغيله. يعاد تجهيز التنبيه بعد إعادة التشغيل وتحديث التطبيق وتغيّر الساعة أو المنطقة الزمنية. لا يُعاد اعتماد موعد مضى أكثر من 30 دقيقة، وتُمنع إعادة عرض الموعد المرسل نفسه. تسجيل الخروج يلغي تنبيهات الصلاة، ويُحتفظ بإعداداتها الشخصية.

التنبيهات **تقريبية** بواسطة `setAndAllowWhileIdle`؛ لا يُطلب إذن التنبيهات الدقيقة، ولا يُدّعى ضمان الثانية المحددة أو العمل بعد الإيقاف القسري. الوضع الصامت وعدم الإزعاج وتوفير البطارية وأذونات النظام قد تمنع الصوت أو تؤخر التنبيه. تنتهي الخطة المحفوظة بعد نحو عام إن لم يفتح المستخدم التطبيق لتجديدها. يلزم إعادة الفتح أيضًا بعد تحديث قواعد التوقيت أو أي تغيير حكومي في مواعيد التوقيت الصيفي.

الصوت المخصص لإشعارات المدرسة العامة يحتاج Android 8+؛ على Android 7 يُرفض حفظ هذا الخيار مع رسالة واضحة، وتبقى الأصوات المضمنة والافتراضي والصامت متاحة. يجب التحقق من هذا السلوك على أجهزة فعلية.

`native-push.ts` يرسل اختيار القناة مع تسجيل الجهاز ويعيد المحاولة عند عودة الاتصال. `backend/src/push` يرسل FCM بالقناة المحفوظة مع الحفاظ على قناة الأجهزة القديمة كخيار افتراضي. لا تتغير أصوات APNs على iOS في هذا التنفيذ؛ مكتبة المعاينة وحفظ التفضيلات على الويب متاحان، لكن لا تُقدَّم وعود بتخصيص إشعارات iOS الأصلية.

## التحقق الآلي

- بناء الواجهة TypeScript/Vite وبناء الخادم NestJS/Prisma.
- `npm --prefix frontend run test:prayer`: حساب تواريخ غزة والتوقيت الصيفي والشتوي، نهاية اليوم، استبعاد الشروق، إعدادات الحسابات، صحة ملفات WAV واختلافها ومستوى الذروة.
- `npm --prefix frontend run test:offline`: اختبارات Service Worker والصلاحيات الحالية وطابور المزامنة والنسخة المحلية القائمة.
- `npm --prefix backend run test:full-offline`: اختبارات الخادم القائمة، ومنها الإشعارات والصلاحيات ومنع تكرار المزامنة.
- اختبار `backend/src/push/push.test.ts` الإضافي يراجع القناة المختارة والصامت والتوافق مع القناة القديمة باستخدام طلبات وهمية، دون إرسال FCM فعلي.
- `npm --prefix frontend run test:e2e:prayer`: واجهات فعلية في Chrome على قياسي هاتف وسطح مكتب للأدوار الستة المفعّلة، مع API اصطناعي بالكامل. يراجع البطاقة والتنقل والعودة وحفظ الإعدادات ومعاينة الصوت والصامت، واستيراد WAV واستمراره بعد إعادة التحميل، وصفحة المواقيت والصوت المضمّن بعد قطع الشبكة فعليًا. ليس اختبارًا لخادم الإنتاج أو أجهزة أندرويد.

## ما بقي قبل الإطلاق

نتائج آخر تحقق محلي: نجح بناء الواجهة والخادم، و9 اختبارات للمواقيت وملفات الصوت، و31 اختبارًا للعمل دون إنترنت، و39 اختبارًا من مجموعة الخادم القائمة. نجحت الاختبارات الستة لملف Push، بما فيها اختبار القناة الجديد. نجحت اختبارات الواجهة الـ12 (ستة أدوار × هاتف وسطح مكتب). تكررت اختبارات المواقيت بنجاح في عملية تعمل بتوقيت America/Los_Angeles. جميع اختبارات الواجهة تستخدم API اصطناعيًا، ولا تمثل اختبار FCM أو تذكيرات Android الفعلية.

1. توفير الملف المرجعي الأصلي وحقوقه لإضافة «صوت المدرسة». لم يُستخرج أي صوت من فيديو.
2. توفير تسجيلات الأذان المرخّصة. الأذان الكامل والمختصر غير مضافين، ولا يوجد تشغيل كامل طويل في الخلفية؛ يتطلب ذلك تنفيذًا واختبارًا منفصلين يناسبان قيود Android. لا تُستبدل التسجيلات الناقصة بعينات وهمية.
3. مطابقة مواقيت غزة مع التقويم المحلي المعتمد.
4. بناء Android والتحقق من Java وSDK ثم اختبار على هاتف حقيقي. تعذر ذلك محليًا برسالة `JAVA_HOME is not set and no 'java' command could be found in your PATH`.
5. على الهاتف: إذن الإشعارات، الإغلاق والخلفية، إعادة التشغيل، تحديث التطبيق، تغيير الساعة، الصيف والشتاء، توفير البطارية وعدم الإزعاج، الصوت الافتراضي والمضمن والمستورد والصامت، الرجوع من الإشعار، وتبديل الحسابات وتسجيل الخروج دون تسرب إعدادات أو تكرار التنبيهات.

لا يُعد هذا تحديثًا جاهزًا للنشر قبل إتمام بنود الاعتماد واختبارات الجهاز والترحيل المذكورة.
