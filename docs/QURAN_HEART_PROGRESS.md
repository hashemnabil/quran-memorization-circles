# مراحل القلب القرآني

القلب مرسوم بـ SVG: المساحات والزهور وأسماء السور عناصر متجهة، دون صورة أو Canvas.

- أصفر: إتمام كل آيات السورة في تسميع الحفظ بتقدير ممتاز.
- أحمر: إتمام مراجعة السورة بممتاز بعد إتمام حفظها.
- أخضر: إتمام تثبيت السورة بممتاز بعد إتمام مراجعتها.
- أبيض: لا يوجد إتمام حفظ مؤهل.

يمكن إكمال المرحلة على عدة جلسات. تُجمع نطاقات الآيات دون تكرار، ولا تُحتسب جلسات غير ممتازة أو مراجعات سبقت إتمام الحفظ أو تثبيت سبق إتمام المراجعة. عند تعديل السجلات أو حذفها، يعاد اشتقاق الإنجاز من السجلات المتبقية، ولا تُمنح نقاط مكافآت إضافية بسبب اللون.

تعاد قراءة السجلات القديمة أيضًا؛ لا يحتاج احتساب الألوان إلى تعبئة بيانات يدوية. تبقى مكافآت السور اليدوية مستقلة عن مراحل القلب.

## النشر

يلزم نشر الخادم والواجهة وتطبيق الترحيل `202611080001_recitation_consolidation` الذي يضيف `CONSOLIDATION` إلى نوع التسميع. لا يحذف الترحيل بيانات أو يغيّر أنواع المراجعات السابقة. أمر `npm run start:prod` في الخادم يطبّق الترحيلات قبل بدء الخدمة، ويمكن تطبيقها يدويًا بواسطة `npm --prefix backend run prisma:deploy` عند استخدام طريقة تشغيل مختلفة.

## التحقق

- `npm --prefix backend run test:achievements`
- `npm --prefix frontend run test:achievements`
- اختبارات التخزين المحلي في `local-api.test.ts` و`offline-engine.test.ts` تغطي الحذف وتعديل التقييم وتقييم التثبيت دون إنترنت.
- `frontend/e2e/achievement-heart.spec.ts` يتحقق من ألوان SVG الثلاثة ووجود 114 مساحة ودعم الشاشات الصغيرة دون الاعتماد على الصور أو Canvas.
