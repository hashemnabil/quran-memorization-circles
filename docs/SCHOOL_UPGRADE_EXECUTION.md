# تطوير مدرسة عبدالله بن عمر — خطة التنفيذ والأدلة

تاريخ الفحص: 2026-10-26. نقطة البداية: `08c1ac96b4242da6a5f493a59e59318ad3cac410`.
فرع العمل: `feat/school-offline-security-upgrade`.

## حدود هذه الدفعة

هذه دفعة تأسيسية وليست تنفيذًا مكتملًا للمواصفات أو إصدارًا جاهزًا للنشر.
لا توجد ترحيلات قاعدة بيانات أو تغييرات على صلاحيات الخادم أو بيانات الإنتاج في هذه الدفعة.
لم يُعتمد شعار أو صوت جديد، ولم تُرفع نسخة إلى Google Play أو يُدمج الفرع.

## البنية التي تم فحصها

- الويب: React 18 وTypeScript وVite وReact Router وReact Query وZustand، مع Tajawal وRTL ومظهر محفوظ محليًا.
- أندرويد: Capacitor 6، الحزمة الحالية `com.abdullahschool.myapp`، وإضافات App وNetwork وPush وSecureStorage، وإضافة إشعارات Java خاصة بالمدرسة. يجب الحفاظ على معرّف الحزمة والتوقيع عند إصدار التحديث.
- الخادم: NestJS وPrisma وPostgreSQL؛ المصادقة تستخدم access/refresh tokens والتحقق من الصلاحيات على الخادم.
- البيانات: قاعدة Dexie باسم `halaqatFull`، جداول مفصولة بمفتاح الحساب، تشفير محلي، طابور دائم، وسجل نتائج عمليات على الخادم لمنع التكرار. يوجد أيضًا مسار حضور قديم يجب إبقاؤه متوافقًا مع العملاء المنشورين.
- المزامنة: `/sync-all` وwatermark وdelta وSocket.IO لإعلان التغييرات. استجابة الشبكة لا يجوز أن تمحو التعديل المحلي المعلق.
- الويب الخلفي: Service Worker يخزن موارد التطبيق، وBackground Sync يطلب من نافذة مفتوحة تنفيذ المزامنة. **لا ينفذ العامل الحالي طابور البيانات بعد إغلاق جميع النوافذ.**

بعض وثائق OFFLINE_FIRST القديمة تصف مرحلة أقدم؛ يجب الرجوع للكود الحالي واختباراته عند تحديد الميزة المتاحة.

| الرجوع | مستمع Capacitor وسجل React Router | تحقق فعلي على أندرويد، إيماءات الرجوع وPredictive Back وفتح الروابط من Push |

| الشعار والأصوات | صور وأصوات حالية في المشروع | عرض نماذج فعلية والحصول على اختيار المستخدم قبل تغيير الافتراضي أو قنوات الإشعارات |
| حذف الاختبار | زر في `StudentDetailsPage.tsx` يستدعي `DELETE /exams/:id` | المسار مفقود. الاختبارات مرتبطة بطلبات ومقررات وسجلات `ExamMilestoneRecord`؛ يلزم سياسة وإعادة احتساب ذرية قبل تمكين حذف سجل معتمد |

## المنفذ في هذه الدفعة

1. رفض صفحات snapshot الناقصة أو المكررة قبل اعتبار التنزيل مكتملًا وقبل حذف السجلات غير الموجودة فيه؛ الحفاظ على مؤشر المزامنة عند الفشل.
2. التحقق من معرّفات الرؤية في delta قبل استخدامها لحذف السجلات المحلية.
3. فصل تشغيل طابور الحساب الجديد عن استجابة حساب سابق، وإعادة فحص الحساب والاتصال بعد فك بيانات الاعتماد وقبل إرسالها.
4. إظهار وقت آخر مزامنة، وعدد العمليات بانتظار تأكيد الخادم، وفشل المزامنة/قراءة التخزين المحلي.
5. رجوع الصفحات المفتوحة مباشرة إلى أصلها، وإغلاق قائمة الحساب قبل الرجوع، وضغطتان للخروج من جذر أندرويد خلال ثانيتين.
6. نقل اختيار المظهر من الشريط الرئيسي إلى إعدادات شخصية مع استمرار تطبيق مظهر النظام، دون تغيير صلاحيات إعدادات الإدارة.
7. شرح من خمس شرائح بالنصوص المطلوبة، مع السابق والتخطي والمؤشرات والسحب باتجاه RTL، وحفظ العلم الحالي دون تصفيره عند التحديث، وإعادة المشاهدة من الإعدادات.
8. عرض الحساب السابق فور استعادة جلسته المحلية أثناء التحقق من `/auth/me` في الخلفية، ودمج استدعاءات الاستعادة المتزامنة، ومنع استجابة حساب سابق من استبدال الحساب الحالي.
9. إتاحة الشرح لأول زيارة للويب مع إبقاء صفحات الخصوصية والحذف والمعلومات متاحة مباشرة.

## ترتيب بقية التنفيذ وشروط قبول كل مرحلة

1. **البيانات والمزامنة:** جرد كل استدعاء كتابة؛ إضافة المحادثات والدعم والمرفقات والتسجيلات المتبقية بعقود DTO وصلاحيات ومنع تكرار وتعارض لكل مجال. لا يُفعّل endpoint عشوائي في الطابور. يجب اختبار انقطاع الاتصال بعد commit وقبل وصول الرد.
2. **السرعة:** عرض البيانات المحلية الصحيحة دون انتظار `/auth/me` أو download، والتحقق في الخلفية. اختبار رفض الجلسة وسحب الصلاحيات قبل اعتبار التغيير آمنًا.
3. **الرجوع:** اختبار تسلسل فعلي لكل صفحة وحوار ورابط إشعار على أندرويد والمتصفح، مع الإيماءات وPredictive Back حسب إصدار Capacitor والنظام.
4. **القفل:** حالة مستقلة عن logout؛ معرّف الحساب ووقت المغادرة يبقيان عبر إنهاء العملية. جهاز أندرويد يستخدم Keystore وBiometricPrompt وبديل PIN محدود المحاولات. فحص 30/59/60/120 ثانية، رجوع الساعة، قتل العملية، التشغيل دون اتصال، البيانات في recent apps والبوابات المنبثقة. سياسة ويب تحفظية عند غياب وسيلة محلية آمنة، ومدة سماح محدودة قبل التحقق من الخادم.
5. **الهوية والشعار:** نماذج أصلية فعلية كاملة ومبسطة وشفافة، ثم اختيار المستخدم؛ لا يُبدّل الشعار الافتراضي قبل الاختيار.
6. **البداية:** Splash أندرويد الرسمية وخلفية ثابتة قبل تحميل WebView، حركة قصيرة دون انتظار الشبكة، وتقليل الحركة.
7. **الشرح:** المنفذ هنا أساس وظيفي؛ تُراجع الرسومات والحركات المميزة لكل شريحة بعد اعتماد الهوية.
8. **الحركة:** مراجعة تقليل الحركة والأجهزة الضعيفة وتجنب إعادة تشغيل الحركة عند كل تحديث للبيانات.
9. **الملف والمحادثات:** إكمال الملف العام والاسم المستعار والصورة المعلقة والردود وحالات إرسال الرسائل، مع بقاء تغيير كلمة المرور خاضعًا للخادم.
10. **الإشعارات والصوت:** ثلاث عينات إشعار وعينات شعار صوتي قابلة للاستماع للاختيار؛ خصوصية شاشة القفل؛ قناة جديدة عند تغيير الصوت؛ لا تشغيل تلقائي للشعار الصوتي.
11. **الإصدار:** مراجعة الصلاحيات لكل دور، اختبار أجهزة حقيقية، build موقع وAPK/AAB تجريبي بتوقيع الإصدار المناسب، وترقية قاعدة بيانات من نسخة سابقة دون محو بيانات أو pending operations.

## التحقق

نتائج هذه الدفعة:

- نجح بناء الواجهة والخادم وفحص أنواع TypeScript.
- نجحت مجموعتا `test:full-offline` و`test:offline` للواجهة، بما فيهما اختبارات IndexedDB والتشفير وعمليات الحسابات. اجتازت اختبارات محرك المزامنة المباشرة الـ31.
- نجحت مجموعتا `test:full-offline` و`test:security` للخادم. لم يُشغّل خادم إنتاج أو تُجرَ تغييرات على قاعدة بياناته.
- شُغّل Chromium فعليًا: نجح 28 سيناريو من 29 في التشغيل الشامل الأخير. كان فشل السيناريو المتبقي بسبب بحث الاختبار عن عنصر `main` بعد الانتقال إلى شاشة الدخول التي لا تحتوي هذا العنصر. صُحح المحدد إلى التأكد من اختفاء بيانات الطالب، ونجحت إعادة تشغيل هذا السيناريو وحده. لم يتغير كود التطبيق بين التشغيلين.
- شملت سيناريوهات المتصفح إعادة تشغيل عملية المتصفح دون إنترنت، بقاء العمليات بعد تسجيل الخروج، اعتماد المزامنة بعد العودة، رفض جلسة مسحوبة مع بقاء التعديلات، الشرح والسحب والإعدادات، والتنقل والبحث محليًا.
- لم تُختبر أجهزة أندرويد أو جميع أدوار الإنتاج فعليًا، ولم تُختبر ميزات القفل أو WorkManager لأنها لم تُنفذ في هذه الدفعة.

الأوامر القابلة لإعادة التشغيل:

```sh
npm --prefix frontend ci
npm --prefix frontend run build
npm --prefix frontend run test:full-offline
npm --prefix frontend run test:offline
npm --prefix frontend run test:e2e:offline
npm --prefix backend ci
npm --prefix backend run build
npm --prefix backend run test:full-offline
npm --prefix backend run test:security
```

لا تستخدم أوامر seed/reset/wipe على الإنتاج. اختبارات المتصفح تستخدم API وهميًا وبيانات اختبار ثابتة؛ نجاحها لا يثبت سلوك خادم الإنتاج أو أجهزة أندرويد. هذه البيئة لا تحتوي Android SDK أو جهازًا متصلًا، ولم تُنفّذ اختبارات فعلية للحسابات الخمسة على أجهزة حقيقية.
